- **Design Direction:** Clean, confident, and calm  
- **Goal:** Reduce cognitive load → maximize learner focus  
- **Tone:** Professional, tech-forward, and inclusive

## 3. Typography

| Type | Font | Weight | Size | Use |
|------|------|---------|------|----|
| **Primary Font** | Inter | 400–700 | 14–20px | General UI text |
| **Display Font** | Poppins | 500–700 | 20–32px | Headings, banners |
| **Monospace (Optional)** | IBM Plex Mono | 400 | 12–14px | Data or technical text |

**Examples:**
- H1: 28px, bold, `#1B1B1B`
- H2: 20px, semibold, `#1B1B1B`
- Body: 14–16px, regular, `#6C6C6C`
- Caption: 12px, light gray

## 5. Key UI Components

### Sidebar
- Dark variant (`#101010` → `#181818`)
- Active state: left 2px Cognify gradient bar  
- Icons: minimal, outlined (Lucide or Feather)
- Avatar, name, and email in top section

### Top Bar
- Search bar: “Search courses, notes, or teachers…”
- Notification & message icons with badge support
- Rounded corners, soft shadow

### Cards
- White background, subtle shadow (`rgba(0,0,0,0.04)`)
- Header icon → title → subtitle → progress bar
- Hover: elevation + border tint with brand color

### Progress Bar
- Rounded edges
- Gradient fill (Cognify brand)
- Background: `#E6E8EB`

### Calendar / Schedule
- Clean grid layout  
- Events color-coded by subject  
- Hover → tooltip or expansion

### Grades Widget
- Circular score badges  
- Color coding:  
  - Green > 85  
  - Amber 60–85  
  - Red < 60  

### Ongoing Lesson Panel
- Live session image, timer, and presence indicator  
- Compact, quick-glance information

### Inbox / Alerts
- Rounded cards  
- Important messages use soft gradient tint background

## 7. Visual Hierarchy

1. **Primary Action:** Cognify Gradient  
2. **Secondary:** Neutral outlined buttons  
3. **Info Cards:** White background, clean separation  
4. **Emphasis Areas:** Gradient headers / tags  

---

## 8. Interaction States

| State | Style |
|--------|--------|
| **Hover** | Subtle shadow or gradient tint |
| **Active** | Pressed-in with darker tone |
| **Disabled** | 40% opacity |
| **Focus** | Blue outline `#3B82F6` |

- Supports light and dark themes

## ✨ Personality Summary

> Cognify’s design is **modern, focused, and emotionally intelligent** — combining warmth (via gradients and soft edges) with precision (via clear layout and typography).  
> The experience should feel like *clarity in motion* — structured, human, and empowering.
